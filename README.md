# Poplar 717 gene atlas (lab address)

This repository only forwards the Tsai lab address
<https://tsailabbioinformatics.github.io/poplar-717-atlas/> to the atlas at
<https://chenhsieh.github.io/poplar-717-atlas/>. Links to a page inside the atlas
(for example `#/gene/PtXaTreH.08G070200`) are kept. If the atlas moves, change the
target in `index.html`.
