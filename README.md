# Poplar 717 gene atlas

A browsable atlas of the 63,960 gene models in the two phased haplotypes of hybrid poplar clone
INRA 717-1B4 (*Populus tremula* × *P. alba*), genome v5.1. Each gene has one page bringing
together its duplication history, its relationship to the other haplotype, gene age
(phylostratum), promoter motifs, a predicted protein model, and expression across 652 public
RNA-seq samples.

**Open the atlas:** <https://tsailabbioinformatics.github.io/poplar-717-atlas/>

Tsai lab, University of Georgia. The data are unpublished dissertation material.

## How to cite

> Hsieh C, et al. Poplar 717 gene atlas (unpublished), version X.Y.Z.
> https://tsailabbioinformatics.github.io/poplar-717-atlas/. Accessed YYYY-MM-DD.

Use the version shown on the atlas's About page. Also cite the underlying study for any expression
data you use; each study page carries its own DOI. A machine-readable record is in
[`CITATION.cff`](CITATION.cff).

## What is in this repository

- `index.html`, `js/`, `css/`: the site. Plain HTML, CSS and JavaScript modules, no build step.
- `data/`: the released data, one JSON file per block of genes plus indexes. This is the artifact;
  it is regenerated by the build, not edited by hand.
- `scripts/`: the build stages and the checks every release has to pass
  (`validate_data.py` for the data, `check.mjs` for the rendered pages).
- `sources/`: small committed inputs and a provenance record for each data layer.
- [`CHANGELOG.md`](CHANGELOG.md): what changed in each release, and why.
- [`TODO.md`](TODO.md): planned enhancements.

Each commit here is one release. The full build needs input files that are not in this
repository, so the committed `data/` is the record.

## Run it locally

Expression values are read by byte range, so use the bundled server rather than a plain static
server:

```
python3 scripts/serve_ranges.py 8931 .
```

then open <http://localhost:8931/>.
